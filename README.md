# 🛒 Zepto SQL Data Analysis

A SQL data analysis project built using PostgreSQL to explore and analyze a real-world Zepto grocery dataset.

## 🚀 Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## 📊 Project Highlights
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Business Insights
- SQL Queries

## 📚 SQL Concepts
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOINS
- CTEs
- Window Functions
